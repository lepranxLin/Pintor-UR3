Pintor-UR3
Proyecto práctico de Robótica de Servicios.

Descripción
Este proyecto utiliza un robot UR3 para reproducir dibujos a partir de imágenes mediante trayectorias generadas automáticamente.

Archivos
UR3_main.py: programa principal.
reading.py: lectura y procesamiento de imágenes.
paint.py: generación de trayectorias.
movement.py: control de movimientos del UR3.
Requisitos
Python 3.10+
OpenCV
URX
Ejecución
python UR3_main.py
